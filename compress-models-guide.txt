═══════════════════════════════════════════════════════════════════
          METHOD 2: USE GLTF-TRANSFORM CLI
═══════════════════════════════════════════════════════════════════

1. Install Node.js from https://nodejs.org/

2. Open PowerShell and run:
   npm install -g @gltf-transform/cli

3. Navigate to your project:
   cd c:\Users\lenovo\portfolioo\ashis-portfolio\models

4. Compress each model:
   gltf-transform draco cocoon-chair.glb cocoon-chair-new.glb
   gltf-transform draco geosynth-table.glb geosynth-table-new.glb
   gltf-transform draco kamdo.glb kamdo-new.glb

5. Backup originals and replace:
   ren cocoon-chair.glb cocoon-chair-backup.glb
   ren cocoon-chair-new.glb cocoon-chair.glb
   (repeat for other models)
